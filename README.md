## ⚡ Как быстро все проверить

### Неделя 3 (Rust CLI)
Здесь проверяется понимание структур данных Solana на чистом Rust без сторонних блокчейн-нод:
```bash
cd week3_rust_cli
cargo run -- demo
```
Скрипт по шагам покажет:
1. Создание аккаунтов Алисы и Боба.
2. Сериализацию инструкций в байты через Borsh.
3. Исполнение транзакций (инициализация счетчика, инкремент, перевод средств).
4. Отработку ошибок: если попытаться перевести больше, чем есть на балансе, или если транзакцию не подписали.

### Неделя 4 (Первая нативная программа)
Контракт лежит в `week4_solana_program/src/lib.rs`.
- **Как задеплоить проще всего:** открыть [Solana Playground](https://beta.solpg.io), скопировать туда `src/lib.rs`, нажать **Build** и **Deploy** в кластер Devnet.
- **Как дернуть с клиента:**
  ```bash
  cd week4_solana_program/client
  npm install
  npx ts-node client.ts <PROGRAM_ID>
  ```
  Клиент сам запросит аирдроп тестовых SOL, создаст аккаунт данных и отправит транзакцию, вернув ссылку на транзакцию в Solana Explorer.

### Неделя 5 (Anchor Counter)
Программа счетчика лежит в `week5_anchor_counter/programs/counter/src/lib.rs`.
- Логика: `initialize`, `increment`, `decrement`, `set_value`.
- В декременте стоит проверка `require!(counter.count > 0, ErrorCode::Underflow)` — счетчик не может стать отрицательным.
- В `set_value` стоит проверка `has_one = authority` — менять значение напрямую может только тот, кто создал счетчик.
- Запуск тестов: `anchor test` (или запустить в Solana Playground вкладку Test).
- Запуск клиента:
  ```bash
  cd week5_anchor_counter/client
  npm install
  npm start
  ```

### Неделя 6 (Децентрализованный профиль на PDA)
Код программы: `week6_pda_user_profile/programs/user_profile/src/lib.rs`.
- Адрес профиля формируется детерминированно из сидов: `[b"user-profile", wallet_pubkey]`.
- Благодаря этому у каждого кошелька гарантированно может быть только один профиль, а для поиска аккаунта не нужны базы данных — адрес вычисляется на лету.
- Реализованы создание (`create_profile`), обновление (`update_profile`) и удаление (`delete_profile`).
- При удалении используется `close = authority`: аккаунт закрывается, а замороженные за аренду SOL возвращаются обратно владельцу кошелька.
- Запуск тестов: `anchor test` (или запустить клиент в папке `client`).

### Неделя 7 (SPL Tokens)
Код и скрипты в папке `week7_spl_tokens/`.
Для проверки достаточно запустить один скрипт:
```bash
cd week7_spl_tokens
npm install
npm start
```
Что делает скрипт:
1. Создает Mint аккаунт токена (9 знаков после запятой).
2. Создает ATA (Associated Token Account) для кошелька создателя.
3. Минтит туда 50 000 токенов.
4. Генерирует второй кошелек и переводит ему 1 500 токенов.
5. Запрашивает финальные балансы из блокчейна и выводит ссылки на транзакции в Explorer.
